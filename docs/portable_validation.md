# Portable validation of regenerated tables

Original provider files are checked against their recorded SHA-256 hashes before
analysis. Frozen protocol files are also byte-exact. These commitments are not
updated during reconstruction, and `.gitattributes` disables checkout newline
conversion because some historical commitments include CRLF bytes.

Three intermediate CSVs are generated by the analysis before the secondary
analysis reads them:

- `data/processed/allogeneic_scores.csv`
- `data/processed/raw_scored_universe_covariates.csv`
- `results/raw_exploratory_NT_sample_reference.csv`

Their original byte commitments remain in `protocol/revision_analysis_plan.json`.
Compressed copies under `protocol/reference_tables/` preserve those exact bytes;
the validator checks each decompressed reference against the original commitment.
The references are validation baselines, not substitute inputs: every numerical
stage regenerates its tables from the provider data and runs on those results.

`src/portable_tables.py` compares regenerated CSV content to these references:

- Column names and order, row counts and order, identifiers, labels and discrete
  numeric values must agree exactly. Row order is retained because seeded
  sampling depends on it. Missing and nonfinite values are rejected.
- Floating fields allow absolute error no larger than
  `max(1e-15, 1e-13 * abs(reference))`. This permits numeric formatting and small
  roundoff differences; it does not permit missing rows or altered identifiers.
- Ranks and ties, relevant score signs, discovery classifications at `q <= 0.05`,
  and matching quintiles must still agree exactly under the downstream parser.

The test suite covers LF/CRLF and numeric-notation equivalence, sub-femtounit
perturbations, and rejection of changed schema, row identity, missingness,
material numbers, discrete values, ranks, signs, thresholds, strata and reference
checksums. Original-source and protocol hash checks remain strict even if only
their newline bytes change.

The full command is `python reproduce.py` from the repository root after provider
acquisition. A focused check is
`python -m unittest discover -s tests -p test_portable_tables.py -v`.
