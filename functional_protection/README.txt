Testing functional immune protection in edited human beta cells

This paper addresses whether an edited human beta-cell preparation can retain
useful secretion while resisting immune injury. This evidence-informed Perspective combines an endpoint decision framework,
exact hypothetical examples, and an experimental design requiring calibration. No new biological experiment
or fitted clinical efficacy estimate is reported. The article and its source ledger
distinguish evidence for the original nominees from other edited human islet products.

Read paper.pdf or paper.docx. The authoritative text is paper_content.json,
generated by write_content.py. source_ledger.json records claims, sources, access
limits and the dependency between clinical reports from one recipient.
study_specification.json records the proposed design and the calibrations still
needed before prospective execution. Null calibration fields are not guessed values. A calibration pathway separates
biological acceptance margins from assay precision and pilot variance. Product
output, increased retention and preserved survivor function are separate claims
that can overlap; improved retention is not required for every functional benefit.

Supplement S1 is supplement_S1.json and foundation_inputs/. It contains eight
exact retained nominee/screen inputs. These do not reproduce the original screen
analysis by themselves. The complete foundation analysis is in the parent
repository: ../src/, ../protocol/, ../data/processed/, ../evidence/, ../results/
and ../tests/. See ../README.md and ../docs/provider_reconstruction.md for its
separate provider-download and reconstruction commands. No archive is required.
The calculations in this directory do not depend on running the foundation pipeline.

Reproduce this Perspective from this directory with Python 3.12+:
    python -m pip install -r requirements.txt
    python reproduce.py

Poppler pdftoppm must be available on PATH. The command validates eight computational
checks, regenerates the exact hypothetical examples and figure, and creates Word.
No empirical observations are simulated, reconstructed from plots or fitted.
The figure is deterministic; manuscript PDF export is a separate step:
    soffice --headless --convert-to pdf --outdir . paper.docx

An installed LibreOffice and Cambria font were used for the designated PDF and
Word layout check. Different fonts or renderer versions can change pagination.
The final supplied paper is ten pages, reviewed page by page. Never interpret a
successful Word build as a newly verified PDF render.
